# homebrew-donsetch

Homebrew tap for [DonSeTch](https://github.com/dondai44423/donsetch) —
web fetch, search and crawl for AI agents.

```
brew tap dondai44423/donsetch
brew install donsetch
```

Binaries are the official GitHub release builds (linux x64/arm64,
macOS arm64/x64). Formula checksums are updated per release.
